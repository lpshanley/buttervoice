# Ghee menu-bar weight study

The recommended asset adds about 0.25 pt to the straight outer wall at an 18 pt display height. The extra ink sits on the inner edge of the outline. The outside contour, the two melts and the facial paths come from the working tree's menu-bar master.

The native PNG is a transparent, black 44 × 38 template matching the file shape the current Tauri app embeds. If adopting this mark, the two files under `menu-bar/` correspond to `src-tauri/icons/menu-bar/`. Continue rendering the PNG as a macOS template so the system supplies its tint.

The comparison shows the working PNG and two designs over a blue sample bar, with enlarged vector contours below. The printed weights are approximate straight-wall measurements. The source app icon, HUD and primary brand master are separate assets.
