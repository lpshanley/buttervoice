## Artwork and scale

The menu mark is a true vector traced from the approved two-melt drawing. The silhouette, eyes and centered smile are separate named paths. The monochrome logos and wordmarks contain outlined lettering for consistent rendering even when fonts are unavailable. The color lockup SVG contains a transparent raster mascot alongside vector lettering.

**Ghee-Original.png is 453 × 430 pixels**, extracted from the approved concept. The 1024 px app-icon exports resample this illustration. For large-format print, use the vector outline or commission a larger shaded master. There is no font installation or external image dependency for the logo files.

Keep white as the light-mode canvas, warm sand inside groups, and butter yellow for selection and listening. The porcelain tile belongs to the app icon. Place transparent logos directly on their intended surface. Open the macOS, Email and Social usage notes for sizing and setup.
